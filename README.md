# ScratchBlox

A portable, 2007-inspired builder with a clean old-school codebase kept in the `old/` folder for reference.

## New 3D build

Open the root `index.html` in a browser for the newer isometric 3D prototype.

## Legacy controls

- WASD or arrows: move
- Space: jump
- Click: build
- Right-click: delete
- 1–5: color change
- R: reset
