# ScratchBlox

A small, browser-playable 2007-style Roblox-inspired building game made with plain HTML, CSS, and JavaScript.

## Run it

Open `index.html` in a browser, or serve the folder with any static web server.

## Controls

- **WASD / arrow keys:** move
- **Space:** jump
- **Left click:** place a block
- **Right click:** remove a block
- **1–5:** choose block color
- **R:** reset the world

The code intentionally avoids frameworks, modules, bundlers, and advanced JavaScript features so it is easier to adapt to Scratch with js2scratch.
